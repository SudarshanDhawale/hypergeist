# Manual verification: AI fields and reminders

Spec: `.kiro/specs/effects-runtime`. Do this list in a real browser before submission. The automated tests use fake timers, a fake `Notification`, scripted providers and a fake `fetch`. They cannot show how a real model, the deployed Worker, real system notifications, a background tab, a closed tab, real zoom or a real phone behave. This file covers those. The Ghost chat is in `docs/manual-verification-ai-ui.md`, the storage in `docs/manual-verification-persistence.md`, and the Worker routes in `docs/manual-verification-worker.md`.

## How to use this file

**Never put a key in a file. Never paste a key into chat or into a screenshot.** Type a key only into the **Key** field of the AI settings window. The app keeps it in memory and asks for it again after a reload.

**Where the cases run.**

- **Local**: `pnpm --filter @hypergeist/web dev`, open `http://localhost:5173`. There is no Worker there, so demo mode answers AI fields from the recorded examples. The demo counter stays hidden.
- **Deployed Worker**: the Worker URL from `docs/deployment.md`, with the shared demo model on. Needed for the cases marked **Deployed Worker**.
- **Real provider**: a provider that allows browser requests and a key you own (see `docs/manual-verification-ai-ui.md`). Needed for the cases marked **Real provider**. Write the provider and the model in the Result column, because results differ by model.

**The two new stacks.**

- **Smart To-Do with Reminders**: a Field for the task, an AI field "When (AI guess)", a Field "When" you can edit, three buttons that you press in order (**1. Read my task**, **2. Use this time**, **3. Remind me**; the cases name them without the number), a button **Add to my list** that you can press at any time, and a list of tasks.
- **Study Deck**: a Field for notes or a topic, three AI fields (flashcards, quiz, walkthrough) with one button each (**Make flashcards**, **Make quiz**, **Make walkthrough**), on three cards linked to each other.

A browser that already stored the demo stacks does not have them until you do case E-33. Use a fresh window (a new profile or a private window with no HyperGeist data) for the other cases, or do E-33 first.

**The time format.** Type a reminder time as `YYYY-MM-DDTHH:mm` or `YYYY-MM-DD HH:mm` in your local time, for example `2026-11-18 17:05`. Where a case says "in 2 minutes", work out the local time two minutes ahead and type it in the Field "When".

**The screen.**

- The menu bar has the button **Reminders (N)**, where N is the number of pending and missed reminders. It opens the **Reminders** window. Each reminder shows its message, the due time, its state (**Pending**, **Fired**, or **Missed while HyperGeist was closed**), and a button **Cancel** (pending) or **Dismiss** (fired or missed). The window states: "Reminders fire only while HyperGeist is open or installed. If the browser or system blocks notifications, they show inside HyperGeist only."
- A fired reminder shows an in-app notice with the text `Reminder: <message>` and a **Dismiss** button. It stays until you dismiss it.
- While an AI field works, it shows **Thinking...**.

**What to write.** In the Result column, write Pass, Fail or Notes. Where a case says "write the wording", copy the text you see, because the exact words depend on the case.
